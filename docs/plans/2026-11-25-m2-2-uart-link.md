# M2.2 — UART Link + CommTask + ESP32 Echo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** First board-level bring-up of the STM32↔ESP32 link: UART1 DMA-IDLE receive + CommTask on the STM32, an ESP-IDF project reusing the frozen protocol library with PING/ACK/echo/heartbeat, and 7-item acceptance evidence.

**Architecture:** Spec `docs/specs/2026-11-25-m2-2-uart-link-design.md` (read it first — the plan argues from it). Ring-drain RX (ISR posts DMA write offset only), stop-and-wait session driven by one prio-2 CommTask per side, blocking TX, ESP link on UART1 GPIO11/12 with UART0 kept as console.

**Tech Stack:** STM32F411 + HAL + FreeRTOS (CMSIS_V1), ESP-IDF v6.0.3 (Windows native, `D:\ESP32\v6.0.3\esp-idf`), Unity host tests (vendored), Makefile/Ninja/cmake, cppcheck 2.13.

**Spec:** `docs/specs/2026-11-25-m2-2-uart-link-design.md`

## Global Constraints

- Protocol library `stm32/middleware/coproc_proto/*` is **frozen — zero edits** (both sides compile the same .c files).
- All hand-written code compiles `-Wall -Wextra` clean (Makefile pattern rules already cover `bsp/`, `platform/`, `app/`).
- Wrap-safe time comparisons: `(int32_t)(now - deadline) >= 0`, never `now >= deadline_abs` (pitfall 20). New host tests must pin this where app-level timing exists.
- CommTask priority **2** — strictly below monitor(4) (IWDG feed discipline, T9).
- `cp_session_t` (1100 B), `cp_frame_t` (516 B), ring (1024 B), buffers: **static allocation only**, never on task stacks.
- Never `cp_session_send(..., CP_CMD_ACK, ...)` (contract, no runtime guard).
- Builds from WSL need `TMPDIR=/home/eli_peng/tmp` prefix (WSL /tmp full).
- Serial evidence flow: start capture **before** flash, read file **after** window ends.
- Push: explicit refspecs only — `git push origin refs/heads/m2-coproc && git push gitee refs/heads/m2-coproc` (pitfall 19). Never `git add -A` (stray FW_SU585 report at repo root).
- Full CI-equivalent cppcheck (whole dir list + `--error-exitcode=1`) locally before every push (pitfall 21).
- Hardware ops (jumpers, power cycles) require asking the user first and waiting for confirmation (AGENTS §9).
- Commits/messages/docs in English; user-facing chat in Chinese.

## Review Focus

The classes of failure the spec implies that task tests could miss — each gets a pinned test/step in the owning task:

1. **Chunked RX bytes** (frame split across ring wrap, half/full events, or `uart_read_bytes` short reads) must never desync the parser — Task 3 tests + Task 6 feed-loop shape.
2. **ms-counter wraparound** in any app-level timing (STM32 tick accumulator, ESP deadline) — Task 6 wrap-step check, Task 2 accumulator style.
3. **ISR legality**: only `xQueueSendFromISR` in the RxEvent callback, nothing else (no parsing, no printf) — Task 5 audit step.
4. **CubeMX regen silently reverting USER CODE** — Task 4 diff checklist.
5. **TX serialization**: the only `cp_session_send` call site is CommTask; `app_comm_send` queue-full returns `CP_ERR_BUF` visibly, never drops silently — Task 6 interface + log-line check.
